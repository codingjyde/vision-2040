# Rhema Nigeria Organisational Knowledge Repository

Owner: Rhema Nigeria

Purpose: Provide the entry point for Rhema Nigeria's long-lived organisational knowledge repository.

Status: Initial scaffold

## Overview

This repository uses the Org Kit structure for documenting an organisation.

It is designed to preserve institutional knowledge, reduce duplication, improve discoverability, and support long-term AI-assisted maintenance.

## Core Files

- [AGENTS.md](AGENTS.md) defines how AI and contributors should work in this repository.
- [ORG.md](ORG.md) defines the organisational documentation framework.

## Repository Structure

- [principles/](principles/index.md) contains enduring organisational principles and decision filters.
- [sources/](sources/index.md) contains foundational source material and extracted facts.
- [programme/](programme/index.md) contains programme execution material, including Vision 2040 workstreams, plans, reports, risks, and meeting papers.
- [capabilities/](capabilities/index.md) contains the enduring organisational capabilities being designed and validated.
- [governance/](governance/index.md) contains authority, accountability, oversight, and decision rights.
- [policies/](policies/index.md) contains approved rules and required standards.
- [playbooks/](playbooks/index.md) contains scenario-based execution guidance.
- [procedures/](procedures/index.md) contains repeatable step-by-step operating instructions.
- [guides/](guides/index.md) contains explanatory, developmental, and onboarding material.
- [templates/](templates/index.md) contains reusable blank document structures.
- [references/](references/index.md) contains external, historical, or supporting reference material.
- [glossary/](glossary/index.md) contains authoritative terms and definitions.
- [decisions/](decisions/index.md) contains decision records and rationale.
- [knowledge/](knowledge/index.md) contains institutional learning, notes, FAQs, and lessons.
- [registers/](registers/index.md) contains indexes used to track documents, decisions, policies, sources, and risks.
- [archive/](archive/index.md) contains superseded and historical material.
