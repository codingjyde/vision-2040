# ADR-0001: Documentation Architecture

Owner: Rhema Nigeria

Purpose: Record the decision to structure this repository using Org Kit principles with separate programme and capability layers.

Status: Approved

## Context

Vision 2040 requires a repository that can preserve organisational knowledge over many years.

The 2026-2027 workstreams are temporary delivery structures, while the capabilities they design are intended to become enduring organisational systems.

## Decision

Use an Org Kit structure with separate layers for:

- organisation-wide artefacts
- Vision 2040 programme execution
- enduring capabilities
- registers
- archive

## Rationale

This avoids trapping stable knowledge inside temporary workstream folders.

It also supports source traceability, version control, cross-referencing, AI-assisted maintenance, and long-term discoverability.

## Consequences

Workstream documents should reference durable capability documents when stable knowledge is produced.

Registers must be maintained as the repository grows.

Documents should be created from templates where possible.
