Owner: Vision 2040 PMO

## Purpose

This matrix shows which source documents each Leadership Guide must be checked against.

It helps reviewers confirm that each guide is grounded in approved source material rather than only in editorial judgement.

## Review Instructions

For each guide:

1. Confirm the official workstream name is present.
2. Confirm any working name is clearly labelled as a working name.
3. Compare the KPI Scorecard with the KPI source section listed above.
4. Confirm the guide does not claim direct ownership of a Vision 2040 goal it only supports indirectly.
5. Confirm all proposed additions are marked as leadership guidance rather than approved source fact.

## Editorial Note

This matrix may change as source documents are refined.

When it changes, review the affected guide rather than assuming the guide remains aligned.
